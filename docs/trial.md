# 試用の手順と記録

大学生 2〜5 人に 15 分ずつ使ってもらい、実データつきの案が作れて、窓口に持っていける形になるかを確かめる。2026-11-06〜07 に行う。

## 確かめること

| 問い | 測り方 | 目安 |
|---|---|---|
| 1. 数字つきの案を作れるか | 15 分で終業画面の「書き写す」まで行けた人数 | 参加者の半分以上 |
| 2. 数字が案の理由になっているか | 書き写した1枚ごとに、根拠の数字が案の理由として読めるかを判定する | 1枚の半分以上 |
| 3. 窓口に出せる形か | 終わったあと「この1枚をこの窓口に出してもいいと思うか」を、はい・いいえ・わからない で聞く | 記録だけ |
| 4. 届け先を知っていたか | 「この窓口を、使う前から知っていたか」を、はい・いいえ で聞く | 記録だけ |
| 5. 歩いて何か見つけたか | 「この町について、知らなかったことを 1 つ見つけたか」を、はい・いいえ で聞き、はいなら何かを書き取る | 記録だけ |
| 6. 返事が来るなら出すか | 「出すと市から 2 週間をめどに返事が来るとしたら、この 1 枚を出すか」を、出す・出さない・わからない で聞く | 記録だけ |
| 7. 就活で使えるなら使うか | 「出した案と返事が就活で話せる記録になるとしたら、また使うか」を、はい・いいえ・わからない で聞く | 記録だけ |

目安は始める前に決めた決めごと。参加者が少ないので統計の意味は無く、作りを直すかどうかの目安として見る。

## 手順

1. https://ms-tech1015.github.io/hatsunichi/ を先に開いておく。読み込みに数分かかることがある
2. 説明は「鳥取の町の困りごとに、数字を1つ選んで案を出す。15 分」だけにする。操作は画面の白兎が教える
3. 15 分たったら止める。終業画面が出ていなければ、時計が 17 時を過ぎるまで歩いてもらうか、案が 1 つ以上あればそこで終業にする
4. 問い3・4・6・7は終業画面で白兎が聞く。案を出したあとに頼んだ人が「自分ならどこまでするか」を1問聞き、答えは1枚の「自分は」の行に載る。どちらも答えなくてよい。「書き写す」でコピーしたものを貼って送ってもらい、問い5だけ口頭で聞く。何を集めるかは、始める前に口頭でも伝える
5. ひとことを頼む。載せてよいか、名前なしでよいかを2回に分けて聞く。断られたら記録しない
6. 動画に使う場合は、画面と手元を撮ってよいかを始める前に別に聞く。顔と声は撮らない。断られたら撮らない。撮ったものは提出の動画にだけ使い、提出後に消してよいかも聞く

## 残すもの

- 人数と、問い1〜7の集計だけ。名前・学年・連絡先・大学名は残さない
- 書き写した1枚は、本人が載せてよいと言ったものだけ下に貼る
- 窓口へ実際に送るかは本人が決める。こちらからは送らない

## 限界

- 参加者が少なく、鳥取の大学生全体のことは言えない
- 窓口が学生の案を受けて動くかは、この試用では測らない。窓口が提案を受け付けると公式ページに書いてあるかは README の「届け先」に書く
- 案が人手不足を減らすかは、この期間では測れない
